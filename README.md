# 💰 Personal Expense Tracker

A modern and intuitive web application designed to help users track, manage, and analyze their daily personal expenses efficiently.

## ✨ Key Features

- **Expense Management:** Easily add, edit, and delete daily income and expenses.
- **Category-wise Tracking:** Organize spending by categories (e.g., Food, Travel, Utilities, Entertainment).
- **Budget Insights:** Clear overview of your spending habits to help you save more.
- **Responsive UI:** Clean, modern, and user-friendly interface built for smooth navigation.

## 🛠️ Tech Stack

- **Backend:** C# / ASP.NET Core MVC
- **Database:** Entity Framework Core / SQL Server
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap

## 🎯 Project Overview

The goal of this project is to provide a practical tool for personal financial awareness while demonstrating full-stack web development capabilities using modern Microsoft technologies.
